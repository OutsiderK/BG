# v0.1 手感闭环迭代任务单

状态：已集成到 `feat/demo-v0-integration`。

本轮目标是让 Demo v0 的单房间战斗“能打、能读、能判断手感”。本轮不扩展房间、武器、道具和正式美术。

## 集成分支

```bash
feat/demo-v0-integration
```

每个 agent 从该分支创建自己的工作分支，完成后提交。

## Agent G：玩家受击与死亡状态

分支建议：`feat/v0-1-player-state`

负责文件：

- `game/scripts/player/player_controller.gd`
- `game/scenes/player/Player.tscn`
- 可新增 `tools/godot/player_state_smoke.gd`

目标：

- 受击后玩家有短暂无敌反馈。
- 死亡后锁定移动、跳跃、冲刺、攻击、展开输入。
- 受击时有轻量击退或速度打断。
- 不改变敌人 AI 和房间逻辑。

验收：

- Godot headless 可加载。
- 玩家死亡后不会继续响应移动和攻击。
- 受击无敌期间重复伤害不会连续扣血。

## Agent H：敌人攻击可读性

分支建议：`feat/v0-1-enemy-telegraph`

负责文件：

- `game/scripts/enemies/enemy_base.gd`
- `game/scenes/enemies/DummyEnemy.tscn`
- 可新增 `tools/godot/enemy_attack_smoke.gd`

目标：

- 敌人攻击前摇有视觉预警。
- 前摇期间被攻击可以被击退或打断。
- 攻击命中窗口和冷却清晰。
- 保留现有追击行为和展开状态追击。

验收：

- 玩家贴近敌人时，敌人不是瞬间造成伤害。
- 攻击前摇期间有颜色/形态变化。
- `tools/godot/enemy_ai_smoke.gd` 仍通过。

## Agent I：命中反馈与战斗可感知性

分支建议：`feat/v0-1-combat-feedback`

负责文件：

- `game/scripts/combat/sword_attack.gd`
- `game/scenes/combat/SwordAttack.tscn`
- 可新增 `game/scripts/fx/`
- 可新增 `game/scenes/fx/`

目标：

- 剑命中敌人时有短命中停顿。
- 命中时生成临时伤害数字或轻量视觉反馈。
- 击退方向稳定，不把敌人推入明显异常位置。
- 不修改玩家主控制脚本和敌人主 AI，除非只加信号兼容。

验收：

- 命中反馈在实际运行中可见。
- 攻击空挥不触发命中反馈。
- Godot headless 可加载。

## Agent J：相机跟随与屏幕反馈

分支建议：`feat/v0-1-camera-feedback`

负责文件：

- `game/scenes/main/Main.tscn`
- `game/scripts/main/main.gd`
- 可新增 `game/scripts/camera/`

目标：

- 添加 Camera2D 跟随玩家。
- 相机限制在当前 demo 房间内。
- 提供可调用的轻量 shake 方法，供后续命中/受击使用。
- 不改玩家、敌人、攻击逻辑。

验收：

- 运行后主视角跟随玩家。
- 玩家在房间左右移动时，相机不会显示房间外太多空区。
- Godot headless 可加载。
