# v0.2 展开可读性迭代任务单

本轮目标是把“平面展开”从状态切换升级为玩家能看懂的核心体验。v0.2 不扩展房间数量、不新增武器/道具、不做正式美术，优先把过渡、落点、lane、风险变化表达清楚。

## 集成分支

```bash
feat/demo-v0-integration
```

每个 agent 从该分支创建自己的工作分支，并在独立 worktree 中工作。

## Agent K：展开/坍缩过渡遮罩

分支建议：`feat/v0-2-unfold-transition-fx`

负责文件：

- `game/scenes/main/Main.tscn`
- `game/scripts/main/main.gd`
- 可新增 `game/scenes/unfold/`
- 可新增 `game/scripts/unfold/unfold_transition_overlay.gd`
- 可新增 `tools/godot/unfold_transition_smoke.gd`

目标：

- 展开进入时显示 0.5s 屏幕压暗、边缘折页/框线、圣纹扩散占位效果。
- 坍缩时显示更短的红色/合拢反馈。
- 过渡视觉通过 `UnfoldManager.unfold_transition_started(kind)`、`unfold_entered`、`unfold_ended(reason)` 驱动。
- 不改 `UnfoldManager` 的状态机核心逻辑。

验收：

- Godot headless 可加载。
- 触发展开过渡时 overlay 节点可见并自动淡出。
- 触发坍缩时 overlay 使用 collapse 样式。

## Agent L：HUD 展开状态与风险提示

分支建议：`feat/v0-2-unfold-hud`

负责文件：

- `game/scripts/ui/hud.gd`
- `game/scenes/ui/HUD.tscn`
- 可新增 `tools/godot/hud_unfold_smoke.gd`

目标：

- HUD 显示当前展开模式：纵平面、展开过渡、展开中、坍缩/冷却。
- 热度满 100 时有可见提示；展开中热度条进入倒计样式。
- 禁展冷却期间显示剩余时间。
- 锚率/侵蚀变化沿用并强化当前风险反馈。

验收：

- `RunState.heat >= 100` 时 HUD 有满能量提示。
- 展开中能看到状态文字和热度消耗。
- 冷却期间能看到不可展开状态。

## 本轮集成验收

自动验收：

```bash
python3 tools/verify_scaffold.py
godot4 --headless --path . --quit
godot4 --headless --path . --script tools/godot/enemy_ai_smoke.gd

```

人工验收：

- Windows 运行 demo。
- 击中敌人攒满热度。
- 按 `1` 展开时能看到过渡反馈、HUD 状态变化和 lane/落点提示。
- 展开中移动规则清楚。
- 再按 `1` 主动结束后位置回到合法地面点，HUD 显示冷却/风险变化。
- 展开中受击坍缩时有坍缩反馈。
