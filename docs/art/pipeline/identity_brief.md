# 折维圣徒 美术 DNA（Identity Brief）

本文件从 [设定.md](../../../设定.md) 中提取美术相关的核心信息，作为所有 `/hatch-*` 调用的稳定身份基线。任何图像生成 prompt 必须把本文件的相关 subject 段落作为参考一起喂入模型。

如果设定.md 有大改，必须先更新本文件再发起新的 hatch 任务，否则会出现身份漂移。

---

## 世界基调

### 世界状态

世界本应有完整厚度（天空、深海、山脉、深渊），但远古众神为封印"灾厄之物"而把世界压成无数二维薄片。普通人只能生活在自己的切片中。

视觉表达要点：

- 一切都像被压扁的纸张/薄片
- 边缘有折痕、切线、错层
- 空间感被人为压缩，但仍要保留前后景层次
- 不是平面卡通，而是"被压成平面"——保留"曾经是 3D"的痕迹

### 旧封印正在老化

切片之间出现裂缝，灾厄力量从裂缝中渗出。

视觉表达要点：

- 裂纹：细而硬，颜色 `#A8447A`（corruption_violet），不弥散
- 灾厄渗出：坐标噪声、线条错位、局部透明、纸张裂开的方式
- 不用红黑污染或脏渍这种俗套表达

### 教会"神赐秩序"

教会宣称二维世界是唯一正确的世界。教会主导秩序、压制真相。

视觉表达要点：

- 圣纹：几何、对称、刻在石碑上、金色 `#C9A24B`
- 教会建筑：高耸、对称、冷光感
- 神圣感是"压迫式神圣"，不是温暖救赎感

## 主角：折维圣徒（player_saint）

### 身份

主角是"叛教圣徒"。曾被教会承认拥有神赐资质并训练为维护二维秩序的工具。后来发现教会隐瞒真相，决定背离教会、寻找新封印方式。

主角拥有罕见的厚度感，灵魂横跨多个相邻切片，被古代祭坛钉入"坐标锚"，所以能在切片间重塑身体。

### 视觉关键词

- **不是华丽骑士**：克制、无名、被工具化的执行者
- **斗篷**：长款、自然下垂、走动时有惯性
- **无脸面罩或头巾**：避免需要五官细节，强化"无名"感
- **圣痕**：身体表面的发光纹路，战斗中会发热；颜色 `#C9A24B`（saint_accent_gold）；位置以胸前/手背为主
- **坐标锚痕迹**：暗示性的几何线条沿身体延伸，颜色 `#9FCCDF`（anchor_coord_cyan），平时隐约可见、展开时强化

### 身体比例

- 头身比 1:5
- 肩宽 36px（128×128 cell 内）
- 斗篷长度 64px
- 默认朝右
- 剑挂在右腰

### 色板

| 用途 | 颜色 |
| --- | --- |
| 斗篷主色（米白） | `#E8E4D4` |
| 衣体次色（暗蓝灰） | `#3D4A5F` |
| 阴影部位 | `#1A2530` |
| 圣痕金色 | `#C9A24B` |
| 轮廓 | `#0F1418` |

### 不要

- 不要圣骑士金甲、不要披风飘逸特效、不要十字架式宗教符号
- 不要"萌"或"少年"感
- 不要绷紧的肌肉表现
- 不要五官细节（面罩遮蔽）

### 主角的"展开"状态视觉

展开时主角从横版纸片转为俯视纸片：

- 身体短暂分解成几何坐标片
- 坐标锚痕（青白色）强化、沿地面扩散
- 圣痕（金色）发热、轮廓微亮
- 不要做成"光球"或"魔法形态"——仍是同一个人，只是空间被掰开

## 巨木薄林（room_thinforest）

### 主题

被压成薄片的古老森林。树木像墙一样从地面升起，树冠延伸到看不见的上边界。

### 分层

- **远景**：薄雾、被压平的树影、模糊枝叶——不参与碰撞、不挡战斗
- **中景**：主要树干和枝台、必须与碰撞平台严格对齐
- **前景**：根须、低矮叶片、透明度低、不能挡战斗

### 色板

| 用途 | 颜色 |
| --- | --- |
| 远景冷调 | `#2A3640`、`#3F5560` |
| 中景树皮 | `#3D2E1F`、`#5A4738` |
| 中景苔藓 | `#5A7283` 加少量绿调 |
| 前景根须 | `#8B7250` |

### 形态要点

- 树干像被压扁的纸柱，侧面看得到"切口"
- 枝条和枝台是几何化的横线/折线，而非自然弯曲
- 没有写实树叶——叶片处理成剪影几何片
- 地面是平直的"切面"，不要泥土起伏

### 不要

- 不要写实森林照片质感
- 不要童话蘑菇/精灵彩色
- 不要满屏雾化

## 敌人：薄林腐化物（enemy_bark_corrupt）

### 来源设定

巨木薄林的怪物是被灾厄侵蚀的森林造物。它们的轮廓由树皮、兽形碎片、影子拼成。

### 视觉关键词

- 低矮、前倾、像树皮残片拼成的兽形
- 攻击时身体局部裂开、露出灾厄裂纹（紫红色 `#A8447A`）
- 死亡时碎成纸片或树屑
- 没有完整的"脸"，但能看出"前端"

### 身体比例

- 头身比约 1:3
- 姿态前倾
- 默认朝向模糊（不是镜像对称即可）

### 色板

- 树皮主色：`#5A4738`、`#3D2E1F`
- 裂纹红：`#8B3A3A`
- 裂纹紫红：`#A8447A`
- 高光骨色：`#F5F0E0`
- 阴影：`#26211C`

### 动作语义

- **idle**：身体轻微起伏、不像植物风吹
- **move**：低姿态前冲、四肢错乱
- **telegraph**：身体裂开、攻击侧的肢体抬起
- **attack**：扑/挥/撞，不要刀剑
- **hurt**：身体压缩、裂纹亮
- **death**：碎成纸片或树屑，保留 0.4 秒后淡出

## Boss：薄林鹿王（boss_thinforest_deer）

### 来源设定

巨木薄林的区域 Boss。纵平面以冲撞、跳跃、树根穿刺攻击；展开后召唤根系网格限制玩家走位。

### 视觉关键词

- 比例放大：cell 192×192
- 鹿形但被严重二维化——四肢、鹿角、躯干都像被压成纸片
- 鹿角是核心识别特征：几何分支、不要写实鹿茸
- 体表有大型灾厄裂纹，亮色 `#A8447A`
- 移动时有"被压扁的笨重感"，不是优雅的鹿

### 不要

- 不要奇幻精灵鹿（金光/水晶角/花瓣）
- 不要 RPG Maker 高级版怪物风
- 不要太多颜色

### 动作要点

- 冲撞前摇 ≥ 0.35s，必须能看清
- 跳跃要有"被压扁的纸片向上拱起"的过渡帧
- 展开阶段：周围根系网格作为分离的 sprite，由场景生成，不和 Boss 本体在同一 sprite sheet

## 武器视觉规则

所有武器（剑、矛、弓、法杖、回旋刃、圣铃）共享：

- 轮廓与主角同样厚度（2px、`#0F1418`）
- 不要花哨纹饰，几何抽象优先
- 攻击弧（FX）使用次色调（保留命中可读性）
- 武器图标 64×64，剪影 + 轻底色（一目了然区分）

### 剑（首版核心武器）

- 直刃单手剑，长度约 1.3 个肩宽
- 不要锯齿、不要符文（保留低饱和素净感）
- 攻击弧颜色 `#E8E4D4` 半透明，淡入快、淡出快

---

## 跨 subject 的统一约束

任何 `/hatch-*` 必须遵守：

1. **轮廓厚度统一**：2px，`#0F1418`
2. **背景必须透明**：alpha threshold 0.05，边缘 8px 安全区
3. **不要文字水印签名**：prompt 中明确写入负面词
4. **保持纸片层次感**：哪怕画的是单个角色，也要让人感觉这个角色从一张薄片中走出
5. **色板锁定**：超出 [style_contract.json](style_contract.json) 调色板的颜色不允许出现（< 5% 像素例外，比如圣痕高光）
